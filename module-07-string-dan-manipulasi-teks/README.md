# MODUL 7: String dan Manipulasi Teks

## Ringkasan Ruang Lingkup Materi
Operasi string, konkatenasi, interpolasi, pencarian teks modern, penggantian, split/join, validasi, format sprintf, heredoc/nowdoc, multibyte, dan regular expression (Regex).

## Tujuan Pembelajaran
Mampu melakukan manipulasi, validasi, dan penyaringan data teks mentah menjadi format yang siap digunakan.

## Ringkasan Modul
Modul 7 (String dan Manipulasi Teks) memberikan pemahaman menyeluruh mengenai operasi string, konkatenasi, interpolasi, pencarian teks modern, penggantian, split/join, validasi, format sprintf, heredoc/nowdoc, multibyte, dan regular expression (regex). Seluruh 20 submodul dirancang terpisah dan mandiri sehingga mudah dipelajari langkah demi langkah.
