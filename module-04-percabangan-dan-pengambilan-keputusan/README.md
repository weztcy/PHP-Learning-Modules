# MODUL 4: Percabangan dan Pengambilan Keputusan

## Ringkasan Ruang Lingkup Materi
Struktur kontrol keputusan: percabangan if, if-else, elseif, nested if, switch-case, match expression, evaluasi truthy/falsy, dan studi kasus algoritma keputusan.

## Tujuan Pembelajaran
Mampu merancang alur logika percabangan kondisional yang efisien dan bersih.
